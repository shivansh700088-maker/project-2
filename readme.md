# Custom Google Search Interface

A simple, practice-focused web project that creates a clean, custom user interface for performing Google searches.

## Features

- **Intuitive UI:** Clean and minimalist interface featuring an input field and a customized search button.
- **Search Redirection:** Seamlessly redirects search queries directly to Google via standard URL encoding.
- **Dual Triggers:** Supports both clicking the search button and pressing the `Enter` key inside the input field.
- **Validation:** Basic validation prevents empty searches and prompts the user to enter a query.

## Files

- `index.html`: Contains the basic markup framework for the search engine layout.
- `style.css`: Contains custom styling rules featuring a warm background, sleek borders, smooth hover animations, and fluid transitions.
- `script.js`: Handles query verification, keypress tracking, event listeners, and secure external redirections.

## Technology Stack

- **HTML5:** Semantic layout mapping.
- **CSS3:** Responsive flexbox positioning, hover transitions, and element styling.
- **JavaScript (ES6):** Event handlers (`click`, `keydown`), DOM manipulation, and dynamic parameter encoding.

## Setup Instructions

1. Clone or download the project files into a local folder.
2. Open `index.html` directly in any modern web browser.
3. Type your search query and press **Enter** or click the **Search** button
